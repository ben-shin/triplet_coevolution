**Acceptance across phases.** Each implementation entry should name its commit, dataset or fixture hashes, exact commands, environment, acceptance result and observed deviations. Record whether a subsystem is available, validated on exact simulations, validated on independent biological data, or still experimental. Preserve the v1 CLI, offline CPU installation, legacy raw rankings, signed statistics, complete score universes, one-to-one matching and source coordinates across migrations. Schema or algorithm changes require an explicit version and replay test. Numeric speed or accuracy claims require a matched reference and scope.

**Owner and data dependencies.** The owner intends free/open-source distribution and has deferred the license choice. The SPDX license, citation authors/identifiers, data redistribution terms and any public release remain owner decisions. During Phase 0 the owner supplied private prepared alignments, matching evidence, labels, a structure and additional outputs. The manifest records data identities and the extent of independent replay. Receipt of a structure or score table alone does not verify the biological assembly, residue correspondence or independent performance. Software gates can proceed on synthetic fixtures. The public cohort and assay records now document their provenance. Authorization to redistribute original inputs remains separate. The package ships compact measurements, registration and replay scripts. [Regression manifest](../benchmarks/gatabc_manifest.json)

**Conditional extensions.** The binary recovery study enumerated fixed-margin tables. General mixed-alphabet fixed-margin sampling needs a validated sampler. A pairwise generative tree model needs convergence and evolutionary calibration. The implemented sparse nested graph uses prespecified L2 penalties. The conditional workflow supports a [mixing-checked, bounded Gibbs bootstrap](gibbs-bootstrap.md). Group sparsity, unrestricted MCMC and pair-coupled evolution require separate validation. The NumPy and optional SciPy nested optimizers were compared, and a pinned MIT protein-only solver provided an independent numerical check. GPU kernels, workflow engines and visualization programs require their own dependency and parity checks. Version constraints and release tools ship. Containers, inferred trees, broad independent pairing truth and validation on predicted ensembles remain optional or unverified. The fluorescence outcomes measure within-protein functional variation. Inter-component higher-order ground truth remains unavailable. Keep biological observations and synthetic expectations attributed to their sources.

**Acceptance across phases.** Each implementation entry should name its commit, dataset or fixture hashes, exact commands, environment, acceptance result and observed deviations. Record whether a subsystem is available, validated on exact simulations, validated on independent biological data, or still experimental. Preserve the v1 CLI, offline CPU installation, legacy raw rankings, signed statistics, complete score universes, one-to-one matching and source coordinates across migrations. Schema or algorithm changes require an explicit version and replay test. Numeric speed or accuracy claims require a matched reference and scope.

**Owner and data dependencies.** The owner intends free/open-source distribution and has deferred the license choice. The SPDX license, citation authors/identifiers, data redistribution terms and any public release remain owner decisions. During Phase 0 the owner supplied private prepared alignments, matching evidence, labels, a structure and additional outputs. The manifest records data identities and the extent of independent replay. Receipt of a structure or score table alone does not verify the biological assembly, residue correspondence or independent performance. Software gates can proceed on synthetic fixtures. Independent held-out systems, verified assay labels and sequence redistribution rights need documented provenance before scientific release. [Regression manifest](../benchmarks/gatabc_manifest.json)

**Conditional extensions.** Fixed-margin table sampling needs a validated sampler. A pairwise generative tree model needs convergence and evolutionary calibration. Sparse/group-regularized models need a defined objective and validation. Optional external optimizers or protein-only solvers, accelerated/compiled/GPU kernels, workflow engines and visualization programs each need license, CPU fallback, dependency and parity checks before being advertised. A dependency lock/container, Hypothesis, inferred trees, local genome annotation sources, cache refresh, higher-order experimental labels and predicted structure support have their own applicability and evidence requirements. Keep biological observations and synthetic expectations attributed to their sources.

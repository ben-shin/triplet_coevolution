### Confirmed engineering and scientific issues

- In `advanced.py`, DCA ranking selects `block.frobenius` before truncation; contact metrics and DCA permutations also use the raw statistic. `potts.py` already computes `block.corrected`. The HTML report describes raw Frobenius ranking. This is a confirmed inconsistency with the commonly preferred APC-corrected contact ranking, not a proven algebraic failure in the inverse covariance solver. Correct scoring everywhere first.
- `structure.py` currently calculates tie-aware pooled AUROC/AP for supplied binary labels. There is no native structural alignment/assembly/distance-map generator or interface-specific, full-denominator precision reporting. Retain the valid existing metric implementation as a reference.
- `threebody.py` scores a saturated *marginal* tensor with a fixed per-cell pseudocount and data-dependent observed state spaces. It does not fit a pairwise maximum-entropy null. Zero-sum centering removes lower-order log terms of the smoothed marginal but does not establish a direct three-body interaction in the full system. Smoothing can itself create nonzero contrasts for distributions originally explainable by pairwise terms; changing supports across replicates also changes the statistic.
- `global_potts.py` is already an actual shared-tensor global three-body pseudolikelihood fit, not a missing feature. It lacks a directly comparable pair-only nested model API and held-out evaluation, uses complete cases, and has limits of 64 variable sites, 250,000 coefficients, and 2,000,000 row-context indices. Do not pretend it is scalable to arbitrary full-length proteins.
- `nulls.py` independently permutes entire B and C rows with A fixed; `phylogeny.py` supplies exchangeability strata. The null breaks cross-component pairwise dependencies too; it is not a pairwise-preserving null or a fitted evolutionary tree model. `advanced.py` refits weights and all enabled statistics for every replicate, serially, with no granular progress or resume. Existing conservative treatment of ties and invalid draws is good; keep and expose diagnostics.
- `sample_candidates` is efficient in memory and permits pure XOR/parity effects, but the default uniform sample of 1,000 triples is not a discovery method for the strongest 21 million possible triples. Do not replace it with a pairwise-only screen, which misses pure synergy.
- `weights.py` computes O(N²L) exact neighbor comparisons, using equal component weights and an overlap requirement per component. `mi.py` runs a Python loop per cross-component site pair. The current dual DCA design caps N×D at 16 million and solve dimension at 4,096; primal solve caps D at 4,096. These are explicit safety limits, not permission to remove them blindly.
- `prepare` loads all rows of all alignments before pairing. The user had to extract the 889 rows per component manually from ~2.3 GB of Stockholm inputs. `run` requires local databases, references/profiles, and external evidence; it does not supply the full iterative JACKHMMER-to-proteome evidence workflow used here.
- Tree at this commit contains no `.github/workflows/`, `LICENSE`, `CITATION.cff`, `CHANGELOG.md`, or standard `AGENTS.md`. Verify the current checkout; add release/CI infrastructure, and request an explicit owner licensing choice rather than inventing one.

## 5. Priority P1 — Distinguish marginal from conditional three-body coupling

This is the central scientific contribution. More complicated scoring is not a substitute for an identifiable hypothesis. Use precise names and definitions for the following distinct quantities.

### 5.1 Local models and information decomposition

For fixed three categorical sites X,Y,Z, use the same jointly observed rows, weights, declared state support and smoothing policy for each compared model. Keep v1 local score and signed co-information as descriptive baselines. Define a hierarchy:

- M1: independent singles, `p1(x,y,z)=p(x)p(y)p(z)`.
- M2: maximum-entropy distribution matching the three pair marginals of the declared target distribution, `p2 ∝ exp(hX+hY+hZ+JXY+JXZ+JYZ)`.
- M3: saturated joint distribution (or a regularized extension with a three-body tensor), `p3 ∝ exp(hX+hY+hZ+JXY+JXZ+JYZ+KXYZ)`.

Implement a numerically stable iterative proportional fitting (IPF) or equivalent convex solver for M2. Use common coherent pair marginals from one joint table, not three independently complete-case MI tables. Initialize strictly positive where appropriate, enforce structural zeros/support consistently, record marginal residuals, iteration counts, tolerances, and status; detect infeasible/inconsistent target marginals or unresolved boundaries. Demonstrate analytic exact cases. Estimate connected third-order information `I3 = D_KL(p3 || p2)` in bits; when M2 exactly matches the pair marginals of p3, this equals `H(p2)-H(p3)`. Distinguish this from signed co-information `I(X;Y)-I(X;Y|Z)` and from log-linear RMS. Do not assume nonzero co-information proves a K tensor. Report likelihood/deviance relative to pair-only models, with explicit effective support and regularization. Do not use naive asymptotic chi-square p-values with sparse, weighted, phylogenetically dependent data. A parametric bootstrap must regenerate/refit the specified model and handle data-dependent state support and weighting consistently.

Add total-prior-mass option (e.g. total α distributed over declared support) alongside legacy per-cell α; also consider shrinkage toward M2 or empirically estimated base frequencies, selected only through defensible validation. Use sensitivity analyses across prior strengths, fixed alphabets, rare-state pooling (explicit mapping frozen on training data), and gap/missing policies. Keep natural-log tensor norms and bits separate. Report possible/observed cells, marginal entropy, support, fraction of mass from prior, prior-to-data ratio, fitted expectation of occupied cells, uncertainty, and an explicit insufficient-information status. Define `K` gauge precisely (zero-sum across every axis); projection of log(smoothed joint) is a marginal interaction parameter, not a global physical energy. For null tests freeze state mapping/support using a prespecified or training-derived rule; test that rare states disappearing do not generate misleading changes of dimension or unequal priors.

### 5.2 Nested conditional models

Extend `global_potts.py` with a true pair-only model (same fields and all chosen within-/between-component pairs) and a pair+selected-triples model sharing the same panel, rows, masks, state encodings, weights, train/validation split and regularization convention. Make models serializable and evaluable on unseen data. Use held-out conditional log loss/pseudolikelihood per site, difference with uncertainty, and model capacity diagnostics. Do not label pseudolikelihood as normalized joint likelihood or use naive likelihood-ratio asymptotics for pseudolikelihood and regularized high-dimensional fits. Compare nested models under held-out clades and simulations; train-only candidate selection, weights, supports and hyperparameters. ## 6. Priority P1 — Statistical controls and phylogenetic validity

### 6.1 Explicit null hypotheses and calibration

Replace the current one-size-fits-all null API with named, independently documented controls. Retain legacy whole-component shuffle with exact semantics. Implement:

1. Unrestricted whole-component matching shuffle: detects cross-component associations above random correspondence; not a test of direct interaction.
2. Within-clade/stratum shuffle: restricts exchangeability, preserves coarse lineage composition but does not automatically preserve full phylogeny. Report group sizes, singleton count, movable fraction and permutation entropy; fail or warn if no informative exchangeability.
3. AB-preserving shuffle of C and analogues: ask whether the third component adds association over a specified preserved pair. Does not preserve all three pair marginals; cannot test universal irreducible three-body effects by itself.
4. Local M2 parametric bootstrap: fit the pairwise maximum-entropy distribution on the same state space, simulate comparable sample/weight/missingness structure, refit M2/M3 on each replicate, compare a defined statistic. Declare iid approximation if used; do not advertise this as phylogenetically calibrated without a validated tree-aware version. A shuffle cannot simultaneously preserve all pair marginals in general. Exact conditional table sampling (fixed pair margins) is a possible advanced method only after validating the sampler, irreducibility/mixing and statistic.
5. Conditional/global pairwise-only generative null: fit a pair-only Potts model on an identical conditioning panel. Simulate using validated Gibbs/MCMC (small exact enumerated checks, multiple chains, burn-in, mixing/ESS diagnostics, stable gauge). Preserve relevant observed masks and sampling design; refit both models. Test whether local marginal triple signals arise even without explicit K, and whether nested conditional K improves prediction. Do not simulate from the ridge inverse covariance estimator as if it were a validated normalized categorical model without justification.
6. Phylogenetic/evolutionary null: tree-conditioned simulations of independent sites or known pairwise couplings with specified substitution/evolution process, taxon/branch mapping, conservation, missingness and ancestral sequence assumptions. Distinguish an independent-site tree null from a pairwise-Potts-on-tree null (the latter is substantially harder). Validate branch lengths, substitution rates/state frequencies, tree uncertainty, mixing for interaction-constrained models. Implement independent-site tree simulations and clade-restricted controls first; label pairwise-plus-tree models experimental until validated. Use a supplied validated Newick tree, or reproducible inferred tree with documented alignment/orthology and optional external programs. Prefer organism/species-tree or marker evidence over an outcome-derived tree when applicable. Assess horizontal transfer and discordant component gene trees; a concatenated tree may obscure conflict.
7. Clade/block bootstrap and leave-one-clade-out stability: uncertainty and reproducibility, not a null p-value. Never treat repeated branches or related homologs as independent evidence.

Each test manifest must state the estimand, null, statistics/direction, resampling unit, whether weights/masks/candidates are recomputed or fixed and why, strata/tree, support, p-value denominator, invalid draws and correction family. Expose statistics individually; allow calibrating DCA/APC or triple scores without recomputing unrelated expensive models. Use exact `(1 + exceedances)/(1 + B)` with conservative tie handling and report Monte Carlo uncertainty. Preserve null replicate identities and candidate coordinate order across workers. Preflight attainable p-values vs number of hypotheses and desired FDR. For M hypotheses, smallest p is 1/(B+1); a single first-rank BH rejection at level α requires B+1 ≥ M/α. Multiple signals can change this requirement; do not claim 999 permutations alone guarantees power for millions of tests. At M=1000 and α=.05 a single rejection needs at least 19,999 draws; at 315,492 it needs 6,309,839. Use justified hierarchical tests, smaller prespecified families, train/test screening or calibrated analytic alternatives where possible. Do not present unadjusted p=.05 as discoveries.

Provide BH and conservative alternatives (e.g. BY or familywise max-statistic when assumptions appropriate); define families across scores/interfaces and report all tested, ineligible and invalid hypotheses. No data-dependent removal of tests after examining p-values. For adaptive allocation or early stopping, implement valid sequential Monte Carlo intervals/decisions or label as exploratory; do not apply fixed-B p-value formula naively after selective stopping. Implement confidence intervals for empirical tail probabilities, max-T where joint null allows, effect size and rank stability. Explain why null calibration and structural enrichment are different evidence.

**Acceptance:** reproducible serial/parallel/resumed nulls at same seed; correct p floor, BH/BY edge cases, ties, invalid draws, all singleton strata; known null calibration and recovery of planted interactions; clade-confounded sequences (unrestricted shuffling may yield false positives); synthetic pair-only latent mediator showing marginal versus conditional distinction; compare empirical false-positive rates with confidence bounds over many simulations. Tests must distinguish hypotheses; no claim that passing one null proves interaction or evolutionary causality.
